수업개요 및 목표
수업개요 | A compiler is a program that translates a program written in a source language into a functionally equivalent program in a target language. This course aims to provide a general understanding of modern compilers. The topics that will be covered in this course include lexical analysis, semantic analysis, and IR optimization.
수업목표 | The objectives of the course are: - Learn how compilers translate a program - Understand the role of compilers - Know the basic algorithms used in modern compilers
