수업개요 및 목표
수업개요 | Modern C++ 프로그래밍 언어에 대한 학습 Learning about the modern C ++ programming language
수업목표 | - Modern C++ 기초 문법 이해 - Vector 등 표준 Container를 통한 자료 처리 학습 능력 함양 - Class와 Inheritance를 통한 객체지향 재사용 개발 방법혼 습득 - Exception Handling을 통한 소프트웨어 안정성 강화 기술 함양 - Understanding Modern C ++ Basic Grammar - Development of data processing learning ability through standard container such as Vector - Object-oriented reuse development method through class and inheritance - Enhancement of software stability enhancement through exception handling
