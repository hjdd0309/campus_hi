수업개요 및 목표
수업개요 | This course deals with understanding and practicing the most frequently used software development methods and tools. As a software development methodology, we learn about agile development methodology and Lean development methodology. Learn about Git tools for software development management. And have an understanding of open source licensing.
수업목표 | - Understanding software development methodology - Understand and use tools useful in software design - Engineering understanding of software performance improvement and efficient reuse method - As a sustainable software developer, students gain the theory and practice of the entire process of software development.
