수업개요 및 목표
수업개요 | This course provides a comprehensive understanding and hands-on practice of widely used software development methodologies and tools. Students will learn Agile development methodology, gain proficiency in Git for version control and project management, and build a solid understanding of open-source licensing.
수업목표 | - Understanding software development methodology - Understand and use tools useful in software design - Engineering understanding of software performance improvement and efficient reuse method - As a sustainable software developer, students gain the theory and practice of the entire process of software development.
