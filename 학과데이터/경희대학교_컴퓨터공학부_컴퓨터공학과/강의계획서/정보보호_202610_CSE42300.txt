수업개요 및 목표
수업개요 | In this course, students learn basic computer network architecture, network security, cryptography, web security, malware. For example, students should understand how HTTPS effectively secure information over the Internet. Also, the course explains how modern web server related systems work.
수업목표 | Students should learn basic cryptography, network, malware problems which are the fundamentals of information security. Overall, students should be able to explain/implement secure/encrypted communication in modern server, how web hacking/malware works.
